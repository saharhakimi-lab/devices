מחשב קצה Host / PC / Server

אופן פעולה

מחשב הוא רכיב הקצה End-Device שבו הכל מתחיל ונגמר! הוא מייצר את המידע בשכבת האפליקציה, עובר את כל תהליך ההכמסה Encapsulation דרך סטאק ה-TCP/IP, ושולח אותה החוצה. כשהוא מקבל חבילה - הוא מפרק אותה מהביטים ועד לטקסט/וידאו שאתם רואים במסך.

נתונים טכניים מרכזיים

כתובת לוגית IP Address IPv4/IPv6
מערכת הפעלה Windows / Linux / macOS
פרוטוקולי יישום HTTP, HTTPS, FTP, DNS
ניהול פורטים Sockets 1-65535

💡 טיפ מטורלל של האחוואנים

המחשב מריץ טבלת ARP פנימית! תרשמו ב-CMD שלכם arp -a ותראו איך המחשב זוכר איזה כתובת IP שייכת לאיזה כתובת MAC פיזית ברשת המקומית שלכם!

שכבת OSI:Layer 2 Data Link
יחידת מידע PDU:Frame מסגרת
כתובת מובנית:MAC Address 48 bit
חיבור פיזי:PCIe / Integrated

כרטיס רשת Network Interface Card - NIC

אופן פעולה

הכרטיס רשת הוא המתרגם והשומר בכניסה למחשב! הוא לוקח את המידע הדיגיטלי מהמעבד והזיכרון, מקודד אותו לאותות חשמליים, אופטיים או גלי רדיו, ושולח אותו לתווך התקשורת. בנוסף, על כרטיס הרשת צרובה כתובת ה-MAC הפיזית הבלעדית שלו שלא משתנית לעולם!

נתונים טכניים מרכזיים

מבנה MAC Hexadecimal 6 Bytes
קצב תעבורה 1Gbps / 2.5Gbps / 10Gbps
מחבר נפוץ RJ-45 / SFP+
מצב עבודה Full-Duplex שידור וקליטה

💡 טיפ מטורלל של האחוואנים

3 הבייטים הראשונים בכתובת ה-MAC נקראים OUI! הם מזהים מאיזה יצרן הכרטיס Intel, Cisco, Realtek. אפשר לדעת איזה חברה יצרה את הרכיב רק לפי ה-MAC!

שכבת OSI:Layer 1 Physical
יחידת מידע PDU:Bits 0101011
סוג התקן:UTP / STP / Fiber
ראש מחבר:RJ-45 / LC / SC

כבלי תקשורת ותשתיות פיזיות

אופן פעולה

העורקים של האינטרנט! התפקיד שלהם הוא להעביר ביטים 0 ו-1 בצורה המהירה והאמינה ביותר. בכבלי נחושת המידע עובר כפולסים חשמליים, ובסיבים אופטיים המידע טס כגלי אור מטורפים בתוך זכוכית דקה הדוקה!

נתונים טכניים מרכזיים

CAT 6 / CAT 6A עד 10Gbps מרחק 55m/100m
סיב אופטי Single-Mode למרחקים ענקיים עשרות ק"מ
סיב אופטי Multi-Mode למרחקים קצרים בתוך דאטה סנטר
תקן חיווט T568B / T568A
🔍 להרחבה תמונה 1
🔍 להרחבה תמונה 2

💡 טיפ מטורלל של האחוואנים

זוכרים כבל מוצלב Crossover וכבל ישר Straight-Through? היום לרוב הסוויצ'ים יש מנגנון מטורף שנקרא Auto-MDIX שמשנה את הפורט אוטומטית גם אם טעיתם בסוג הכבל!

שכבת OSI:Layer 2 Data Link
יחידת מידע PDU:Frame מסגרת
טבלה מרכזית:MAC Address Table
טכנולוגיית ליבה:VLANs, Trunk, STP

מתג רשת Switch - L2

אופן פעולה

הסוויטש הוא המרכזיה החכמה של הרשת המקומית LAN. כשמגיעה אליו מסגרת Frame, הוא מסתכל על כתובת ה-MAC של היעד, בודק בטבלת ה-MAC הפיזית שלו באיזה פורט היעד נמצא, ושולח את המידע **רק לפורט הזה**! בשונה מהרכזת הישנה Hub שהיתה צועקת לכולם Broadcast.

נתונים טכניים מרכזיים

חלוקת רשתות VLANs 802.1Q
חיבור בין סוויצ'ים Trunk Port 802.1Q Tagging
אבטחת פורטים Port Security Sticky MAC
מניעת לולאות STP Spanning Tree Protocol

💡 טיפ חשוב

🌐 לסימולטור סוויטש

אם הסוויטש לא מכיר את כתובת ה-MAC של היעד, הוא יבצע היצפה Unknown Unicast Flooding וישלח את המסגרת לכל הפורטים חוץ מהפורט שנכנסה ממנו, עד שהוא ילמד אותה!

יחידת מידע PDU:Packet חבילה
טבלה מרכזית:Routing Table
תפקיד על:מחבר בין רשתות שונות

נתב Router - L3

אופן פעולה

הראוטר הוא מנהל התנועה העולמי! התפקיד שלו הוא לקשר בין רשתות שונות נפרדות למשל הרשת הביתית שלכם לרשת האינטרנט העולמית. הראוטר בוחן את כתובת ה-IP של היעד בכל חבילה, בודק בטבלת הניתוב שלו Routing Table מה הנתיב הכי טוב להגיע לשם, ומעביר אותה הלאה.

נתונים טכניים מרכזיים

סוגי ניתוב Static Routing / Dynamic OSPF, RIP
תרגום כתובות NAT / PAT Public vs Private IP
חלוקת IP DHCP Server / Relay
ניתוב בין VLANs Router-on-a-Stick Sub-Interfaces

💡 טיפ מטורלל של האחוואנים

ראוטר עוצר הודעות Broadcast! שום הודעת הצפה מ-VLAN אחד לא תעבור דרך הראוטר ל-VLAN אחר אלא אם הגדרתם ניתוב במפורש. הוא השומר של גבולות הרשת!

שכבת OSI:Layers 1 & 2 Wi-Fi
יחידת מידע PDU:Radio Frames 802.11
תדרים נפוצים:2.4GHz / 5GHz / 6GHz
תקן מרכזי:IEEE 802.11ax Wi-Fi 6

רכיבי גישה אלחוטיים Access Point / Wireless Router

אופן פעולה

נקודת גישה אלחוטית AP ממירה את האותות החשמליים שמגיעים מהסוויטש הקווי לגלי רדיו באוויר. היא משדרת את שם הרשת SSID ומאפשרת למכשירים ניידים להתחבר לרשת הקווית ללא כבלים.

נתונים טכניים מרכזיים

אבטחה אלחוטית WPA2-Personal / WPA3-Enterprise
תדר 2.4GHz טווח ארוך, חודר קירות, איטי יותר
תדר 5GHz מהיר מאוד, טווח קצר, פחות הפרעות
מנגנון גישה CSMA/CA Collision Avoidance

💡 טיפ מטורלל של האחוואנים

ברשת קווית משתמשים ב-CSMA/CD זיהוי התנגשויות, אבל באוויר אי אפשר לזהות התנגשות תוך כדי שידור, ולכן באלחוט משתמשים ב-CSMA/CA מניעת התנגשויות מראש!
